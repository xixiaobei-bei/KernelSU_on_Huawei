# 如何适配

## 联系适配

首先确保内核版本>=4.9

:::note

安卓内核的版本号命名方式与日常不同，例如：

4.19>4.4

这是因为"4.00"与"0,19“分开对比，转换成无小数形式对比，变为"4"与"19",其中的"4"为大版本，"0.19"为小版本，大版本与大版本对比，小版本与小版本对比

:::
